# BizCore V271.5.35 — Customer & Supplier Details UI

Based on V271.5.34.2.

- Customer and Supplier detail windows use the compact approved two-tab design.
- Information tab: company and contacts, national address, existing change history, and supplier notes.
- Activity & Usage tab: existing calculations/usage and recent transactions, expanded by default.
- Typography: 500 only for company names/headings; fields and values regular 400, no heavy bold.
- Compact modal surfaces with one scroll area as necessary, fixed footer.
- No Firestore, data model, filtering, sorting, or calculation changes.
- Requires authenticated visual confirmation.
